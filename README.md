# Kai

A collection of Rust clients and utilities for "otaku" websites.

This repository is a Cargo workspace. Each client is published as its own crate.

## Websites
- [Fansubs / Kage Project](http://fansubs.ru): `kai-fansubs`
- [MangaLib](https://mangalib.me): `kai-mangalib`

## Contributing

Issues and pull requests are welcome. Please keep code and documentation clear and simple.
